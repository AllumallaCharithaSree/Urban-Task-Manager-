# Urban Task Manager

A modern and responsive web-based task management application designed to help users organize daily tasks efficiently. The project features a clean interface for creating, managing, and tracking tasks, making productivity simple and intuitive.

## 🚀 Live Demo

https://allumallacharithasree.github.io/Urban-Task-Manager-/

## 📌 Features

- Create and manage tasks
- User-friendly and responsive interface
- Modern dashboard layout
- Simple navigation
- Interactive design using HTML, CSS, and JavaScript
- Mobile-friendly design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/AllumallaCharithaSree/Urban-Task-Manager-.git
```

2. Open the project folder.

3. Open `index.html` in any modern web browser.

No installation or additional dependencies are required.
